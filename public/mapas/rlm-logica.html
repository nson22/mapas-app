01

Proposições e Conectivos

tabela-verdade e valores lógicos

Proposição é uma sentença declarativa que pode ser julgada verdadeira (V) ou falsa (F). Não são proposições: perguntas, ordens, exclamações e sentenças abertas (com variável, como "x + 1 = 5").

p ⊻ qDisjunção exclusivaou p ou qos dois têm o mesmo valor

p ↔ qBicondicionalp se e somente se qp e q têm valores diferentes

  • Tautologia: sempre V. Contradição: sempre F. Contingência: depende dos valores.
Condicional: a linha que mais cai

Falso condicional só ocorre com antecedente verdadeiro e consequente falso. Se o antecedente é falso, o condicional é verdadeiro, seja qual for o consequente.

Treino autoral 1
Qual o valor lógico de "Se 2 + 2 = 5, então a Terra é plana"?
Ver resposta
Verdadeiro — O antecedente é falso, então o condicional é verdadeiro.
Treino autoral 2
Quantas linhas tem a tabela-verdade de uma proposição com três proposições simples?
Ver resposta
8 — 2 elevado a 3 = 8.

Negações e Equivalências

De Morgan, contrapositiva e condições

Equivalências do condicional

FormaÉ equivalente a p → q?
~q → ~p (contrapositiva)Sim
~p ∨ qSim
q → p (recíproca)Não
~p → ~q (inversa)Não
Exemplo: condicional

"Se chove, então a rua molha."
Contrapositiva: se a rua não molha, então não chove.
Também equivale: não chove ou a rua molha.

Exemplo: negação

Negar "Se chove, então a rua molha" é "Chove e a rua não molha".

Suficiente e necessária

Em p → q, p é condição suficiente para q e q é condição necessária para p. "p somente se q" e "q se p" também significam p → q.

Erros clássicos

Negar "p ou q" trocando por "não p ou não q" (o certo é "não p e não q"). Negar o condicional escrevendo "se p, então não q". Confundir contrapositiva com recíproca.

Treino autoral 3
Qual é a negação de "Ana estuda e Bruno trabalha"?
Ver resposta
Ana não estuda ou Bruno não trabalha — De Morgan: a negação de "e" é "ou", com cada parte negada.
Treino autoral 4
Qual é a negação de "Se a prova for fácil, então todos passarão"?
Ver resposta
A prova é fácil e algum não passará — Negação do condicional: p ∧ ~q; a negação de "todos passarão" é "algum não passará".
Treino autoral 5
Qual das afirmações é equivalente a "Se o servidor cair, o sistema para"? (A) Se o sistema para, o servidor caiu. (B) Se o servidor não cair, o sistema não para. (C) Se o sistema não para, o servidor não caiu. (D) O servidor cai e o sistema não para.
Ver resposta
C — C é a contrapositiva. A é a recíproca, B é a inversa, D é a negação.

Diagramas

Pegadinhas

"Algum" significa pelo menos um, então "algum A é B" não exclui "todo A é B". "Nem todo A é B" equivale a "algum A não é B". A negação de "todo" nunca é "nenhum".

Treino autoral 6
Qual é a negação de "Todos os servidores da sala usam o sistema"?
Ver resposta
Algum servidor da sala não usa o sistema — Negar "todo" resulta em "algum não".
Treino autoral 7
A negação de "Nenhum candidato foi reprovado" é:
Ver resposta
Algum candidato foi reprovado — A negação de "nenhum" é "algum".
04

Argumentos e Validade

premissas, conclusão e falácias

Argumento é um conjunto de premissas e uma conclusão. Ele é válido quando, sendo as premissas verdadeiras, a conclusão é necessariamente verdadeira. Validade não é verdade: um argumento pode ser válido com premissas falsas.

FormaEstruturaVálida?
Modus ponensp → q; p; logo qSim
Modus tollensp → q; ~q; logo ~pSim
Silogismo hipotéticop → q; q → r; logo p → rSim
Silogismo disjuntivop ∨ q; ~p; logo qSim
Afirmação do consequentep → q; q; logo pNão (falácia)
Negação do antecedentep → q; ~p; logo ~qNão (falácia)

Como testar validade

  • Atribuição de valores: suponha todas as premissas verdadeiras e deduza o valor de cada proposição simples; veja se a conclusão sai verdadeira.
  • Por absurdo: tente deixar a conclusão falsa com todas as premissas verdadeiras; se conseguir, o argumento é inválido.
  • Diagramas, para premissas com todo, algum e nenhum.
PremissasConclusãoVálido?
Todo A é B; todo B é CTodo A é CSim
Todo A é B; algum B é CAlgum A é CNão (o B que é C pode estar fora de A)
Nenhum A é B; algum C é AAlgum C não é BSim
Treino autoral 8
"Se estudo, passo. Não passei. Logo, não estudei." O argumento é válido?
Ver resposta
Sim (modus tollens) — Do condicional e da negação do consequente conclui-se a negação do antecedente.
Treino autoral 9
"Se estudo, passo. Passei. Logo, estudei." O argumento é válido?
Ver resposta
Não (afirmação do consequente) — É possível ter passado sem estudar (por exemplo, por sorte).
Treino autoral 10
Premissas: "Se Ana viaja, Bia fica" é verdadeira e "Bia não fica" é verdadeira. O que se conclui?
Ver resposta
Ana não viaja — Modus tollens: como Bia não fica, o consequente é falso; para o condicional ser verdadeiro, o antecedente deve ser falso.

Mnemônicos de concurso

macetes para fixar

Mnemônicos e macetes de memorização. Alguns variam de uma fonte para outra; use os que funcionarem para você e confira sempre com o conteúdo do mapa.

Condicional: quando é falso

“Vera Fischer é Falsa”: V → F = F. O condicional só é falso com antecedente verdadeiro e consequente falso.

Negação do condicional

MANE: Mantém a primeira e Nega a segunda. ~(p → q) = p ∧ ~q.

Contrapositiva

NI: Nega e Inverte. p → q ≡ ~q → ~p.

Outra equivalência

NEY MA: Nega a primeira ou (Y) Mantém a segunda. p → q ≡ ~p ∨ q.

Suficiente e necessária

Em p → q, p é suficiente e q é necessária.

E, OU e bicondicional

E só é verdadeiro se todos forem V; OU só é falso se todos forem F; bicondicional é V quando os valores são iguais.

Quantificadores

Nega TODO = ALGUM NÃO; nega ALGUM = NENHUM; nega NENHUM = ALGUM. “Nem todo” = algum não.
