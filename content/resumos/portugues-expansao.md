::::::category{id="morfologia" short="Morfologia" tag="A FORMA DA PALAVRA" title="Morfologia — a forma da palavra" count="como ela é construída e escrita"}

:::::branch{id="estrutura" num="01" title="Estrutura das Palavras" kicker="morfemas: as unidades mínimas de significado"}

Toda palavra pode ser decomposta em morfemas — elementos menores com significado ou função próprios\: radical, vogal temática, tema, desinências, afixos e vogais/consoantes de ligação.

### Radical

O morfema lexical — a parte fixa que carrega o significado principal da palavra. É o mesmo em toda uma família de palavras\:

| Radical | Palavra |
| --- | --- |
| :hl[cant-] | cantar |
| :hl[cant-] | cantor |
| :hl[cant-] | cantiga |

### Vogal temática

Liga o radical à desinência. Nos **verbos** (vogal temática verbal), indica a conjugação\:

| Vogal temática | Conjugação e exemplo |
| --- | --- |
| :hl[-a] | 1ª conjugação\: falar |
| :hl[-e] | 2ª conjugação\: entender |
| :hl[-i] | 3ª conjugação\: dividir |

Nos **nomes** (vogal temática nominal), aparecem principalmente -a, -e, -o\: *livr-o, dent-e, past-a*. Nomes terminados em consoante (como *par*) recuperam a vogal temática -e no plural (*mar-e-s*). Nomes terminados em vogal tônica, como *café*, não têm vogal temática — ela nunca ocorre em sílaba tônica.

### Tema

É a junção do radical com a vogal temática\: *fala-r, entende-r, dividi-r* (temas verbais); *livro-s, pasta-s* (temas nominais). Quando não há vogal temática, tema e radical coincidem.

### Desinências

::::grid{cols="2"}

:::example{tag="Nominais"}

Indicam gênero e número\: -o masculino (amig**o**), -a feminino (amig**a**), -s plural (amigo**s**).

:::

:::example{variant="alt" tag="Verbais"}

Modo-temporais (indicam modo e tempo) + número-pessoais (indicam pessoa e número).

:::

::::

:::group{label="Modo-temporais"}

| Desinência | Tempo e exemplo |
| --- | --- |
| :hl[-va/-ia] | pret. imperfeito do indicativo (falava, corria) |
| :hl[-ra] | pret. mais-que-perfeito (falara) |
| :hl[-ria] | futuro do pretérito (falaria) |
| :hl[-sse] | pret. imperfeito do subjuntivo (falasse) |

:::

:::group{label="Número-pessoais"}

| Desinência | Pessoa e exemplo |
| --- | --- |
| :hl[-o] | 1ª singular (falo) |
| :hl[-s] | 2ª singular (falas) |
| :hl[-mos] | 1ª plural (falamos) |
| :hl[-m] | 3ª plural (falam) |

:::

### Prefixos e sufixos (afixos)

Juntam-se ao radical para formar uma nova palavra derivada — o prefixo vem antes, o sufixo depois.

::::grid{cols="2"}

:::example{tag="Prefixo"}

desigual (des- + igual) · infeliz (in- + feliz) · refazer (re- + fazer)

:::

:::example{variant="alt" tag="Sufixo"}

caprichar (capricho + -ar) · normalmente (normal + -mente) · lavável (lavar + -ável)

:::

::::

### Vogais e consoantes de ligação

Surgem só por razão fonética, entre dois morfemas, sem carregar significado próprio — facilitam a pronúncia. Também chamadas de infixos\:

| Palavra | Formação |
| --- | --- |
| :hl[gasômetro] | gás-ô-metro |
| :hl[parisiense] | Paris-i-ense |
| :hl[chaleira] | chá-l-eira |
| :hl[cafezal] | café-z-al |

:::callout{tag="Atenção"}

Na junção dos morfemas podem ocorrer omissões e alterações fônicas\: **carteiro** = cart(a) + eiro, com omissão do "a"; **cantávamos/cantáveis** mostram o "a" alterado para "e" por influência do "i" seguinte.

:::

::::branch{id="acentuacao" num="02" title="Acentuação Gráfica" kicker="a marcação segue a sílaba tônica"}

As regras dependem da posição da sílaba tônica\: oxítona (última sílaba), paroxítona (penúltima) ou proparoxítona (antepenúltima).

### Monossílabos tônicos

| Terminação | Exemplos |
| --- | --- |
| :hl[A, AS] | dá, gás |
| :hl[E, ES] | fé, três |
| :hl[O, OS] | pôs, nós |
| :hl[ÉU, ÉUS] | céu, réu |
| :hl[ÉI, ÉIS] | réis |
| :hl[ÓI, ÓIS] | dói, sóis |

### Oxítonas

| Terminação | Exemplos |
| --- | --- |
| vogal tônica -a, -e, -o (+s) | pajé, vocês, crachá, aliás, mocotó, após |
| ditongo nasal -em, -ens | além, também, parabéns |
| ditongo aberto -éu, -éi, -ói (+s) | mausoléu, herói, anéis |

### Paroxítonas

São a maioria das palavras da língua — só acentuam nas terminações abaixo\:

| Terminação | Exemplos |
| --- | --- |
| -r, -l, -n, -x, -ps | caráter, fóssil, tórax, bíceps |
| -ã, -ão (+s) | órfã, órgão, bênção |
| -um, -uns | álbum, fórum, quóruns |
| -om, -ons | próton, elétrons, nêutrons |
| -us | vírus, ônus, bônus |
| -i, -is | júri, lápis, grátis |
| -ei, -eis | jóquei, pônei, saudáveis |

### Proparoxítonas

:::callout{tag="Regra sem exceção"}

Toda proparoxítona é acentuada\: líquido, lâmpada, ácaro, médico, tática, exército.

:::

### Acordo Ortográfico de 1990 (vigente desde 2009)

| Caso | Antes → Depois |
| --- | --- |
| Ditongos abertos -oi, -ei em paroxítonas | jóia → joia, geléia → geleia |
| -i, -u precedidos de ditongo em paroxítonas | feiúra → feiura, baiúca → baiuca |
| -o tônico fechado de -oo em paroxítonas | vôo → voo, enjôo → enjoo |
| Hiato -eem (3ª plural pres. ind./subj.) | vêem → veem, dêem → deem |

::::::category{id="sintaxe" short="Sintaxe" tag="A PALAVRA NA FRASE" title="Sintaxe — a palavra na frase" count="como o verbo se conecta ao seu complemento"}

:::::branch{id="transitividade" num="03" title="Transitividade Verbal" kicker="que tipo de complemento o verbo exige" tone="sintaxe"}

Um verbo transitivo não tem sentido completo sozinho — precisa "transitar" até um complemento. A transitividade classifica exatamente que tipo de complemento é exigido.

::::grid{cols="3"}

:::example{tag="VTD · transitivo direto"}

Complemento **sem** preposição obrigatória — o objeto direto. "Terminei **a análise**." (terminei o quê?)

:::

:::example{variant="alt" tag="VTI · transitivo indireto"}

Complemento **com** preposição obrigatória — o objeto indireto. "Duvido **da sua honestidade**." (duvido de quê?)

:::

:::example{variant="gold" tag="VTDI · bitransitivo"}

Dois complementos\: um sem e um com preposição. "Enviei **os postais** (OD) **aos clientes** (OI)."

:::

::::

### Intransitivo

Tem sentido completo sozinho — não exige complemento. "João nasceu." já é uma oração completa.

:::callout{tag="Cuidado com a pegadinha"}

Um verbo intransitivo pode vir seguido de mais palavras sem deixar de ser intransitivo — desde que o que vem depois seja um **adjunto adverbial**, não um complemento. "João nasceu :u[ontem]." / "A planta morreu :u[de sede]." / "Adormeci :u[cedo]." — em todos, o verbo continuaria com sentido completo mesmo sem o trecho sublinhado.

:::

::::branch{id="regencia" num="04" title="Regência Verbal e Nominal" kicker="qual preposição cada verbo ou nome exige" tone="sintaxe"}

A regência verbal estuda a relação entre o verbo (regente) e o complemento (regido) — e, sobretudo, qual preposição esse complemento exige. Muitos verbos mudam de regência conforme o sentido empregado — é aí que mora a pegadinha de prova.

### Verbos de regência variável

| Verbo · sentido | Regência | Exemplo |
| --- | --- | --- |
| Assistir – ver | :hl[com "a"] | Vamos assistir ao filme. |
| Assistir – dar assistência | sem prep. | Sempre assistiu pessoas mais velhas. |
| Assistir – pertencer | :hl[com "a"] | Assiste aos prejudicados o direito de indenização. |
| Assistir – morar | :hl[com "em"] | Eu assisto em Lisboa. |
| Chegar / Ir | :hl[com "a"] | Chegamos ao local; vou à biblioteca. |
| Custar – ser custoso | :hl[com "a"] | Aquela decisão custou ao filho. |
| Custar – valor | sem prep. | Aquela casa custou caro. |
| Obedecer / Desobedecer | :hl[com "a"] | Obedeça ao pai! (norma culta — informalmente usa-se sem prep.) |
| Proceder – ter fundamento | intransitivo | Essa desconfiança não procede. |
| Proceder – ter origem | :hl[com "de"] | Procede de situações passadas. |
| Pagar / Perdoar – a pessoa | :hl[com "a"] | Paguei-lhe assim que pude (nunca "paguei-o"). |
| Pagar – a coisa | sem prep. | Paguei a dívida. |
| Esquecer / Lembrar – pronominal | :hl[com "de"] | Esqueci-me do fogão ligado. |
| Esquecer / Lembrar – não pronominal | sem prep. | Esqueci o fogão ligado. |
| Querer – desejar | sem prep. | Quero ficar aqui. |
| Querer – estimar | :hl[com "a"] | Queria muito aos seus amigos. |
| Aspirar – respirar/absorver | sem prep. | Aspirou todo o ar do escritório. |
| Aspirar – pretender | :hl[com "a"] | Aspirou ao cargo de ministro. |
| Informar | bitransitivo | Informei o acontecimento aos professores. |
| Implicar – consequência | sem prep. | O pedido implicará um novo orçamento. |
| Implicar – embirrar | :hl[com "com"] | Implica com tudo! |
| Morar / Residir | :hl[com "em"] | Mora no fim da rua. |
| Namorar | sem prep. (norma culta) | Namorou Maria durante anos. |
| Preferir | :hl[bitransitivo, "a" fixo] | Prefiro carne a peixe (nunca "do que"). |
| Simpatizar(-se) | :hl[com "com"] | Simpatiza com os mais velhinhos. |
| Agradar – causar prazer | sem prep. | A música agradou o público. |
| Agradar – mimar | :hl[com "a"] | A avó agradava ao neto com doces. |
| Comparecer | :hl[com "a"] | Compareceu à reunião com os diretores. |
| Confiar – ter confiança | :hl[com "em"] | Confio em você. |
| Confiar – entregar | bitransitivo | Confiou o segredo ao amigo. |
| Faltar | :hl[com "a"] | Faltou à aula (ou intransitivo absoluto\: "faltaram alunos"). |
| Gostar / Necessitar | :hl[com "de"] | Gosto de literatura clássica. |
| Observar / Satisfazer | sem prep. | Observei a reação do público. |

### Regência nominal

Adjetivos e substantivos também exigem preposições fixas em relação ao termo que completam\:

| Preposição | Exemplos |
| --- | --- |
| A | alheio a análogo a apto a contemporâneo a contíguo a curioso a grato a nocivo a paralelo a preferível a propício a propenso a próximo a sensível a |
| DE | alheio de ambicioso de capacidade de contemporâneo de curioso de falto de longe de natural de perto de próximo de suspeito de |
| COM / PARA COM | liberal com misericordioso com, para com incompatível com |
| EM / PARA | bacharel em hábil em indeciso em inepto para propenso para capacidade para |

:::example{variant="gold" tag="Satisfeito"}

com, de, em, por — o único termo do quadro com quatro preposições possíveis.

:::

:::::branch{id="sinonimos" num="05" title="Sinônimos" kicker="sentidos próximos ou equivalentes" tone="semantica"}

Termos distintos com sentidos parecidos — mas raramente idênticos. Cada palavra carrega um matiz específico, e a diferença entre "sinônimos" aparece justamente no contexto\:

::::grid{cols="2"}

:::example{tag="Sinônimos, mas com nuance"}

"Muda-se a casa, preserva-se o **lar**." — "casa" e "lar" podem ser sinônimos, mas aqui carregam sentidos ligeiramente diferentes (espaço físico x vínculo afetivo).

:::

:::example{variant="alt" tag="Uso diferenciado"}

"O casal não **discutiu**; ele **brigou**." — discutir e brigar têm sentido próximo, mas foram usados com valores distintos na mesma frase.

:::

::::

:::callout{tag="Atenção"}

A capacidade sinonímica de um termo não pode ser avaliada fora de contexto — a banca costuma testar exatamente essa nuance.

:::

:::::

:::branch{id="antonimos" num="06" title="Antônimos" kicker="grafias diferentes, sentidos opostos" tone="semantica"}

Muitos antônimos nascem de um processo de **prefixação** — uma partícula de negação ou contrariedade se junta à palavra original\:

| Palavra original | Com prefixo |
| --- | --- |
| :hl[bendizer] | maldizer |
| :hl[simpático] | antipático |
| :hl[progredir] | regredir |
| :hl[concórdia] | discórdia |
| :hl[explícito] | implícito |
| :hl[ativo] | inativo |
| :hl[esperar] | desesperar |
| :hl[simetria] | assimetria |
| :hl[pré-nupcial] | pós-nupcial |

:::

:::branch{id="paronimos" num="07" title="Parônimos" kicker="grafia/som parecidos, sentido diferente" tone="semantica"}

O oposto do que se vê em sinônimos/antônimos\: aqui a **escrita é semelhante**, mas os campos semânticos não têm proximidade nenhuma — são os pares clássicos da pegadinha de prova.

**infligir** impor ou aplicar castigo × **infringir** desobedecer, transgredir

**retificar** consertar, corrigir × **ratificar** confirmar, validar

**emergir** vir à tona × **imergir** afundar, mergulhar

**descrição** ato de descrever × **discrição** reserva, prudência

**cavaleiro** homem que anda a cavalo × **cavalheiro** homem educado

**comprimento** extensão × **cumprimento** saudação

:::

:::::branch{id="homonimos" num="08" title="Homônimos" kicker="mesma pronúncia, sentidos distintos" tone="semantica"}

Dividem-se, pela gramática normativa, em perfeitos e imperfeitos — e os imperfeitos se subdividem em mais dois tipos\:

| Tipo | Grafia | Pronúncia | Exemplo |
| --- | --- | --- | --- |
| :hl[Perfeitos] | idêntica | idêntica | "caminho" (verbo) / "o caminho" (substantivo) |
| Imperfeitos – homógrafos | idêntica | difere na vogal tônica | "o almoço" (subst., *ô* fechado) / "eu almoço" (verbo, *ó* aberto) |
| :wine[Imperfeitos – homófonos] | diferente | idêntica | seção / sessão / cessão |

::::grid{cols="2"}

:::example{tag="manga"}

"Ele rasgou a manga da camisa" (roupa) x "Colheu uma manga madura" (fruta) — homônimo perfeito.

:::

:::example{variant="alt" tag="colher"}

"Vou colher flores" (verbo, *colhêr*) x "Pegue uma colher de sopa" (substantivo, *cólher*) — homógrafo.

:::

::::

:::::branch{id="mnemonicos" title="Mnemônicos de concurso" kicker="macetes para fixar"}

Mnemônicos e macetes de memorização. Alguns variam de uma fonte para outra; use os que funcionarem para você e confira sempre com o conteúdo do resumo.

::::grid{cols="2"}

:::example{tag="Regência: o “a”"}

**Assistir (ver) A; Aspirar (desejar) A; Obedecer A; Preferir A; Chegar A.** Sem preposição\: **namorar**, **visar** (mirar), **assistir** (dar assistência).

:::

:::example{tag="Complementos"}

**VTD\: quem? o quê? (sem preposição). VTI\: a/de/em quem? o quê? (com preposição).**

:::

:::example{tag="Ratificar × retificar"}

**Ratificar = confirmar; Retificar = corrigir** (RE-fazer).

:::

:::example{tag="Emergir × imergir"}

**E-mergir = sair, vir à tona; I-mergir = entrar, mergulhar.**

:::

:::example{tag="Eminente × iminente"}

**Eminente = elevado, ilustre; iminente = que está prestes a acontecer** (a iminência).

:::
