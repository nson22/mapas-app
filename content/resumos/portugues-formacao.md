:::::branch{id="substantivo" num="01" title="Substantivo" kicker="nomeia seres, coisas, sentimentos e fenômenos"}

É a palavra que dá nome a tudo o que percebemos — pessoas, objetos, sentimentos, ações, fenômenos. Classe variável\: flexiona em número, gênero e grau.

### Quanto à origem e formação

::::grid{cols="2"}

:::example{tag="Comum × Próprio"}

Comum designa a espécie de forma genérica (homem, cidade, rio). Próprio designa um indivíduo específico, com inicial maiúscula (João, São Paulo, Tietê).

:::

:::example{tag="Primitivo × Derivado"}

Primitivo não vem de outra palavra (carro, cabelo). Derivado nasce de outro vocábulo, por prefixo ou sufixo (carrão, cabeleireiro).

:::

:::example{tag="Simples × Composto"}

Simples tem um único radical (flor, homem). Composto tem mais de um radical (beija-flor, homem-bomba).

:::

:::example{tag="Concreto × Abstrato"}

Concreto designa um ser autônomo, real ou imaginário (carro, fada). Abstrato designa ação, sentimento, estado, conceito (medo, alegria, liberdade).

:::

### Substantivo coletivo

Designa um grupo de seres da mesma espécie\:

| Substantivo | Grupo |
| --- | --- |
| :hl[matilha] | cães |
| :hl[alcateia] | lobos |
| :hl[colmeia] | abelhas |
| :hl[frota] | veículos |

### Flexão de grau

::::grid{cols="2"}

:::example{tag="Diminutivo"}

Sufixos -inho(a), -zinho(a)\: carrinho, animalzinho. Frequentemente usado para afetividade.

:::

:::example{variant="alt" tag="Aumentativo"}

Sufixos **-ão, -aço, -ona**\: casarão, filmaço. Pode indicar desprezo ou intensidade.

:::

::::

### Flexão de gênero

::::grid{cols="2"}

:::example{tag="Biforme"}

uma palavra para cada gênero — **cachorro/cachorra**, **poeta/poetisa**

:::

:::example{variant="alt" tag="Uniforme"}

uma única palavra para os dois gêneros, subdividida em três tipos\: **Epiceno**, **Sobrecomum** e **Comum de dois gêneros**

:::

::::

| Tipo | Regra | Exemplos |
| --- | --- | --- |
| :hl[Epiceno] | Animais — um só gênero fixo para a espécie | a cobra, a foca, o besouro |
| :hl[Sobrecomum] | Pessoas — um só gênero, seja quem for | a criança, a vítima, o monstro |
| :hl[Comum de dois gêneros] | Uma palavra; o artigo é que marca o gênero | o/a estudante, o/a artista |

### Flexão de número

| Terminação do singular | Regra | Exemplos |
| --- | --- | --- |
| :hl[Vogal ou ditongo oral] | Acrescenta-se “s” | pá/pás, pai/pais, herói/heróis |
| :hl[Terminados em “m”] | Troca-se “m” por “ns” | jovem/jovens, álbum/álbuns, refém/refens |
| :hl[Terminados em “r” ou “z”] | Acrescenta-se “es” | colher/colheres, raiz/raízes, juiz/juízes |
| :hl[Terminados em “al, el, ol, ul”] | Troca-se “l” por “is” | papel/papéis, anzol/anzóis, túnel/túneis |
| :hl[Terminados em “il” (oxítonos)] | Troca-se “il” por “is” | funil/funis, fuzil/fuzis |
| :hl[Terminados em “il” (paroxítonos)] | Troca-se “il” por “eis” | fóssil/fósseis, projétil/projéteis |
| :hl[Terminados em “s” (oxítonos e monossílabos)] | Acrescenta-se “es” | país/países, mês/meses, gás/gases |
| :hl[Terminados em “s” (paroxítonos e proparoxítonos)] | Invariável | lápis/lápis, ônibus/ônibus, tênis/tênis |
| :hl[Terminados em “x”] | Invariável | o tórax/os tórax, a fênix/as fênix |
| :hl[Terminados em “ão”] | Três formas\: “ãos”, “ões” ou “ães” | cidadão/cidadãos; mamão/mamões; cão/cães |

:::callout{variant="warn" tag="Exceções em “al/el/ol/ul”"}

Nem toda palavra terminada em “al” segue a troca por “is”\: **mal → males** e **cônsul → cônsules** apenas acrescentam “es”.

:::

### Plural dos substantivos compostos

| Regra | Exemplos |
| --- | --- |
| Unidos por hífen\: substantivo + substantivo, substantivo + adjetivo ou numeral + substantivo — **flexionam-se os dois elementos** | decretos-leis, cirurgiões-dentistas, cachorros-quentes, más-línguas, segundas-feiras |
| Sem hífen; ou verbo + substantivo; ou elemento invariável + palavra variável; ou palavras repetidas — **flexiona-se só o segundo elemento** | autopeças, girassóis, guarda-roupas, beija-flores, vice-campeões, alto-falantes, pisca-piscas |
| Substantivo + preposição + substantivo; ou quando o segundo elemento limita o primeiro (tipo, finalidade) — **flexiona-se só o primeiro elemento** | pés de moleque, mãos de obra, bananas-prata, salários-família, cidades-satélite |
| Verbo + advérbio; verbo + substantivo plural; verbos antônimos; frases substantivas — **os dois elementos ficam invariáveis** | os bota-fora, os saca-rolhas, os guarda-vidas, os senta-levanta, os Deus-nos-acuda |

:::example{tag="Mais de um plural aceito"}

Algumas palavras admitem mais de uma forma\: **padre-nosso** → padre-nossos ou padres-nossos; **salvo-conduto** → salvo-condutos ou salvos-condutos.

:::::branch{id="adjetivo" num="02" title="Adjetivo" kicker="atribui qualidade, condição ou estado ao substantivo"}

Concorda com o substantivo a que se refere em gênero e número. Quanto ao radical, é **simples** (garoto surdo) ou **composto** (garoto surdo-mudo); quanto à origem, **primitivo** (homem belo) ou **derivado** (homem belíssimo).

:::callout{tag="Atenção"}

O adjetivo **pátrio** (relativo a cidade, estado, país ou continente — carioca, paulistano, brasileiro) é sempre grafado com **letra minúscula**, mesmo quando o nome próprio de origem é maiúsculo.

:::

### Grau comparativo

::::grid{cols="3"}

:::example{tag="Superioridade"}

Matemática é **mais** difícil **que** Português.

:::

:::example{tag="Igualdade"}

Matemática é **tão** difícil **quanto** Português.

:::

:::example{variant="alt" tag="Inferioridade"}

Matemática é **menos** difícil **que** Português.

:::

::::

### Grau superlativo

**Relativo** — compara dentro de um conjunto (Português é a mais difícil das disciplinas). **Absoluto** — intensifica sem comparar, podendo ser\:

::::grid{cols="2"}

:::example{tag="Analítico"}

Com advérbio\: o professor é **muito** exigente.

:::

:::example{tag="Sintético"}

Com sufixo\: o professor é exigent**íssimo**.

:::

::::

### Flexão dos adjetivos compostos

Em regra, só o segundo termo varia\: meninos afro-brasileiros. Exceção\: se o composto tem um substantivo na formação (adjetivo + substantivo), nada varia — camisas amarelo-ouro, sapatos verde-abacate. Alguns são sempre invariáveis\: azul-marinho, cor-de-rosa, zero-quilômetro.

:::::

:::::branch{id="numeral" num="03" title="Numeral" kicker="quantidade exata ou posição em série"}

::::grid{cols="2"}

:::example{tag="Cardinais"}

Formas básicas dos números\: um, dois, cem, mil. Alguns variam em gênero (duas) e número (milhão/milhões). "Ambos(as)" é numeral.

:::

:::example{tag="Ordinais"}

Indicam ordem numa sequência\: primeiro, segundo, décimo. Variam em gênero e número; às vezes valem como adjetivo ("carne de primeira").

:::

:::example{tag="Fracionários"}

Indicam parte de um todo\: meio, um quarto, três avos. Variam em gênero e número.

:::

:::example{variant="alt" tag="Multiplicativos"}

Indicam múltiplos\: dobro, triplo, quíntuplo. Invariáveis — exceto com valor de adjetivo ("dose dupla").

:::

### Numerais coletivos

Substantivos que indicam quantidade exata, flexionando em número\: dúzia/dúzias, dezena/dezenas, centena/centenas.

::::branch{id="artigo" num="04" title="Artigo" kicker="especifica ou generaliza o substantivo"}

Vem antes do substantivo e determina seu sentido — de forma precisa (definido) ou vaga (indefinido).

| Tipo | Formas | Função | Exemplo |
| --- | --- | --- | --- |
| :hl[Definido] | o, a, os, as | Individualiza algo já conhecido ou mencionado | Ganhamos **a** bicicleta que esperávamos. |
| :hl[Indefinido] | um, uma, uns, umas | Indica de forma vaga, ainda não mencionada | Joana convidou **uns** amigos estrangeiros. |

:::callout{tag="Cuidado"}

Não confunda o artigo indefinido "um" com o numeral "um"\: o artigo indica indeterminação; o numeral indica quantidade exata (Comprei **um** carro, não dois).

:::

::::grid{cols="2"}

:::example{tag="Pronome substantivo"}

Substitui o nome\: "Um homem bateu à porta. **Ele** era meu irmão."

:::

:::example{variant="alt" tag="Pronome adjetivo"}

Acompanha e qualifica o nome, sem substituí-lo\: "**Aquele** homem bateu à porta."

### 1) Pessoal

**Caso reto** — função de sujeito. **Caso oblíquo** — complementam o verbo.

| Pessoa | Caso reto | Caso oblíquo |
| --- | --- | --- |
| :hl[1ª singular] | eu | me, mim, comigo |
| :hl[2ª singular] | tu | te, ti, contigo |
| :hl[3ª singular] | ele, ela | o, a, lhe, se, si, consigo |
| :hl[1ª plural] | nós | nos, conosco |
| :hl[2ª plural] | vós | vos, convosco |
| :hl[3ª plural] | eles, elas | os, as, lhes, se, si, consigo |

Pronomes de tratamento são usados em situações formais — exceto "você", o único informal\:

| Forma | Uso |
| --- | --- |
| :hl[Você] | informal |
| :hl[Senhor(a)] | pessoas mais velhas |
| :hl[V. Ex.ª] | autoridades |
| :hl[V. Mag.ª] | reitores |
| :hl[V.S.ª] | correspondência |
| :hl[VM] | reis/rainhas |
| :hl[V.A.] | príncipes |
| :hl[V.S.] | o Papa |
| :hl[V. Em.ª] | cardeais |
| :hl[V. Rev.mª] | religiosos |

:::callout{tag="Formas lo/la/no/na"}

Os oblíquos **o, a, os, as** mudam de forma conforme a terminação do verbo. Depois de **r, s, z** (que somem) ou da palavra “eis”\: viram **lo(s), la(s)** — provocá-la (provocar + a), fi-las (fiz + as), fá-lo (faz + o). Depois de ditongo nasal (**-am, -em, -ão, -õe**)\: viram **no(s), na(s)** — anunciaram-na, propõe-nas.

:::

### 2) Possessivo

Transmite ideia de posse\: meu/minha, teu/tua, seu/sua, nosso/nossa, vosso/vossa (+ plurais). "A **sua** bolsa ficou na escola."

### 3) Indefinido

Substitui ou acompanha o substantivo de maneira vaga\: "**Alguém** deve me explicar a matéria."

| Tipo | Exemplo |
| --- | --- |
| :hl[Variáveis] | algum, nenhum, muito, pouco, todo, outro, certo, vário, tanto, quanto, qualquer, um |
| :hl[Invariáveis] | quem, alguém, ninguém, tudo, nada, outrem, algo, cada |

### 4) Relativo

Retoma um termo já dito, evitando repetição\: "Os temas sobre **os quais** falamos são complexos."

| Tipo | Exemplo |
| --- | --- |
| :hl[Variáveis] | o qual, a qual, cujo, cuja, quanto |
| :hl[Invariáveis] | quem, que, onde |

:::callout{variant="warn" tag="Cujo(a, os, as)"}

Liga dois substantivos com ideia de posse\: o primeiro é o possuidor, o segundo é o possuído. **Concorda com a coisa possuída, nunca com o possuidor**, e **nunca vem seguido de artigo**. “Os pais **cujos filhos** estudam” (filhos dos pais — concorda com “filhos”). Se o termo regente exigir preposição, ela vem antes de “cujo”\: “a lei **a cujos** artigos o jurista se referiu” (referir-se **a** algo).

:::

### 5) Interrogativo

Usado em perguntas diretas ou indiretas\: "**Quem** estava com Maria na festa?"

### 6) Demonstrativo

Indica a posição de algo no discurso, no tempo ou no espaço.

| Pronome | Função | Espaço | Tempo | Enumeração |
| --- | --- | --- | --- | --- |
| :hl[este, esta, isto] | Catafórica (aponta adiante) | Perto de quem fala | Presente | Último elemento citado |
| :hl[esse, essa, isso] | Anafórica (aponta para trás) | Perto de quem ouve | Passado/futuro próximos | — |
| :hl[aquele, aquela, aquilo] | Exofórica (fora do texto) | Longe de ambos | Passado/futuro distantes | Primeiro elemento citado |

Exemplo de enumeração\: "Paulo e Renato são vizinhos. **Este** conserta carros e **aquele** vende peças." (este = último citado, Renato; aquele = primeiro citado, Paulo)

:::group{label="Também são demonstrativos"}

| Palavra | Exemplo |
| --- | --- |
| :hl[mesmo(s), mesma(s)] | as mesmas roupas |
| :hl[próprio(s), própria(s)] | os próprios meninos |
| :hl[semelhante(s)] | não diga semelhante coisa |
| :hl[tal, tais] | não viva com tal preocupação |
| :hl[o(s), a(s)] | quando equivalem a isto/aquele(s)\: quero a da direita |

:::::branch{id="verbo" num="06" title="Verbo" kicker="ação, estado ou fenômeno · flexiona em modo, tempo e pessoa"}

### Estrutura da forma verbal

1. **Radical** — traz o significado. Ex.\: *fal-* (falar), *com-* (comer), *part-* (partir).
2. **Vogal temática** — indica a conjugação\: *-a* (1ª, -ar), *-e* (2ª, -er), *-i* (3ª, -ir). Radical + vogal temática = **tema**.
3. **Desinência modo-temporal** — indica o modo (indicativo, subjuntivo, imperativo) e o tempo (presente, pretérito, futuro).
4. **Desinência número-pessoal** — indica pessoa e número (eu, tu, ele, nós, vós, eles).

::::grid{cols="2"}

:::example{tag="sonhavam"}

radical *sonh-* + vogal temática *-a* + desinência modo-temporal *-va* (pretérito imperfeito do indicativo) + desinência número-pessoal *-m* (3ª plural)

:::

:::example{variant="alt" tag="corria"}

radical *corr-* + vogal temática *-e* + desinência modo-temporal *-ia* (pretérito imperfeito) + desinência número-pessoal ausente (1ª ou 3ª singular)

:::

::::

### Locução verbal

Verbo auxiliar (conjugado) + verbo principal (particípio, gerúndio ou infinitivo), funcionando como um único verbo\: **Estava** lendo (gerúndio) · **Tenho** feito (particípio) · **Seremos** premiados (particípio). Auxiliares mais comuns\: ser, estar, ter, haver — além de poder e dever.

### Quanto à regularidade

| Tipo | Característica | Exemplos |
| --- | --- | --- |
| :hl[Regular] | O radical se mantém em toda a conjugação | levanto, levantas, levanta... |
| :hl[Irregular] | O radical se modifica | caber (caibo), dizer (digo, disse), querer (quis) |
| :hl[Anômalo] | Total diversidade de radicais | ser (sou, fui, era, seja), ir |
| :hl[Defectivo] | Faltam formas na conjugação | abolir, precaver, reaver |

### Verbos impessoais

Não têm sujeito — usados só na 3ª pessoa do singular\:

| Tipo | Exemplos |
| --- | --- |
| :hl[Haver (Sentido de existir)] | Havia muitos pacientes à espera |
| :hl[Fazer (Tempo decorrido)] | Faz dois anos que me mudei |
| :hl[Fenômenos da natureza] | chover, anoitecer, ventar, nevar, amanhecer |

:::callout{tag="Atenção"}

"Existir" **não** é impessoal — concorda normalmente com o sujeito\: "Exist**em** motivos que te façam mudar de ideia."

:::

### Verbos pronominais

Exigem um pronome oblíquo correspondente ao sujeito **(me, te, se, nos, vos, se)**.

::::grid{cols="2"}

:::example{tag="Essenciais"}

Sempre exigem o pronome\: "Não **me** arrependo do que faço."

:::

:::example{variant="alt" tag="Acidentais"}

O pronome é opcional\: "Penteou-**se** e foi dormir" / "Penteou todas as bonecas."

:::branch{id="adverbio" num="07" title="Advérbio" kicker="modifica verbo, adjetivo ou outro advérbio" variant="invar"}

Indica uma circunstância — modo, lugar, tempo, entre outras. "O vizinho fala **bastante alto**"\: *bastante* intensifica *alto*, que modifica *fala*.

| Tipo | Exemplos |
| --- | --- |
| :hl[Modo] | bem, mal, devagar, depressa, -mente (cuidadosamente) |
| :hl[Intensidade] | muito, pouco, bastante, tão, quase, demais |
| :hl[Lugar] | aqui, ali, lá, dentro, fora, perto, longe |
| :hl[Tempo] | hoje, já, sempre, nunca, cedo, ainda |
| :hl[Negação] | não, nem, tampouco |
| :hl[Afirmação] | sim, certamente, decerto |
| :hl[Dúvida] | talvez, possivelmente, porventura |

### Locução adverbial

Duas ou mais palavras com função de advérbio\:

- "Fez os deveres **às pressas**" (modo)
- "Vire **à direita**" (lugar)
- "**Em breve** nos veremos" (tempo)

:::branch{id="conjuncao" num="09" title="Conjunção" kicker="liga orações ou palavras de mesmo valor" variant="invar"}

Coordenativas ligam orações **independentes**; subordinativas ligam orações **dependentes** entre si.

### Coordenativas — 5 tipos

| Tipo | Ideia | Exemplos de conectivo |
| --- | --- | --- |
| :hl[Aditivas] | Soma | e, nem, não só...mas também |
| :hl[Adversativas] | Oposição | mas, porém, contudo, todavia |
| :hl[Alternativas] | Escolha | ou, ou...ou, já...já |
| :hl[Conclusivas] | Conclusão | logo, portanto, por isso |
| :hl[Explicativas] | Motivo | que, porque, pois (antes do verbo) |

### Subordinativas — 10 tipos

| Tipo | Exemplos de conectivo |
| --- | --- |
| :hl[Integrantes] | que, se |
| :hl[Causais] | porque, já que, uma vez que |
| :hl[Comparativas] | que, do que, como |
| :hl[Concessivas] | embora, ainda que, mesmo que |
| :hl[Condicionais] | caso, contanto que, desde que |
| :hl[Conformativas] | segundo, conforme, consoante |
| :hl[Consecutivas] | de forma que, de modo que |
| :hl[Temporais] | logo que, quando, assim que |

Geralmente acompanhada de ponto de exclamação. Pode ser um som vocálico (Ah!), uma palavra (Puxa!) ou uma **locução interjetiva** — grupo de palavras com o mesmo papel (Meu Deus!, Ora bolas!).

:::::category{id="acentuacao" short="Acentuação|Gráfica" tag="REGRAS DE SÍLABA TÔNICA" title="Acentuação Gráfica" count="a marcação segue a sílaba tônica"}

::::branch

As regras de acentuação dependem da posição da sílaba tônica\: oxítona (última sílaba), paroxítona (penúltima) ou proparoxítona (antepenúltima).

### Monossílabos tônicos

São acentuados os monossílabos terminados em\:

| Terminação | Exemplos |
| --- | --- |
| :hl[A, AS] | dá, gás |
| :hl[E, ES] | fé, três |
| :hl[O, OS] | pôs, nós |
| :hl[ÉU, ÉUS] | céu, réu |
| :hl[ÉI, ÉIS] | réis |
| :hl[ÓI, ÓIS] | dói, sóis |

### Oxítonas

| Terminação | Exemplos |
| --- | --- |
| :hl[vogal tônica -a, -e, -o (+s)] | pajé, vocês, crachá, aliás, mocotó, após |
| :hl[ditongo nasal -em, -ens] | além, também, parabéns |
| :hl[ditongo aberto -éu, -éi, -ói (+s)] | mausoléu, herói, anéis |

### Paroxítonas

São a maioria das palavras da língua — só acentuam nas terminações abaixo (fora delas, não acentuam)\:

| Terminação | Exemplos |
| --- | --- |
| :hl[-r, -l, -n, -x, -ps] | caráter, fóssil, tórax, bíceps |
| :hl[-ã, -ão (+s)] | órfã, órgão, bênção |
| :hl[-um, -uns] | álbum, fórum, quóruns |
| :hl[-om, -ons] | próton, elétrons, nêutrons |
| :hl[-us] | vírus, ônus, bônus |
| :hl[-i, -is] | júri, lápis, grátis |
| :hl[-ei, -eis] | jóquei, pônei, saudáveis |

### Proparoxítonas

:::callout{tag="Regra sem exceção"}

Toda proparoxítona é acentuada\: líquido, lâmpada, ácaro, médico, tática, exército.

:::

### Acordo Ortográfico de 1990 (vigente desde 2009)

Quatro grupos de palavras perderam o acento\:

| Caso | Antes → Depois |
| --- | --- |
| :hl[Ditongos abertos -oi, -ei em paroxítonas] | jóia → joia, geléia → geleia |
| :hl[-i, -u precedidos de ditongo em paroxítonas] | feiúra → feiura, baiúca → baiuca |
| :hl[-o tônico fechado de -oo em paroxítonas] | vôo → voo, enjôo → enjoo |
| :hl[Hiato -eem (3ª plural pres. ind./subj.)] | vêem → veem, dêem → deem |
